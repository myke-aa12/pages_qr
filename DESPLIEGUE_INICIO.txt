🎯 3 PASOS PARA LANZAR:
─────────────────────────────────────────────────────────────────

PASO 1: Crear Droplet en Digital Ocean (5 min)
  • Ve a: https://cloud.digitalocean.com/
  • Crea Droplet Ubuntu 22.04 LTS ($5-6/mes)
  • Copia la IP

PASO 2: Ejecutar script automático (5 min)
  ssh root@TU_IP
  wget https://raw.githubusercontent.com/myke-aa12/pages_qr/main/deploy-auto.sh
  bash deploy-auto.sh

PASO 3: Configurar credenciales (1 min)
  nano /home/appuser/pages_qr/.env
  → Reemplaza valores dummy con tus credenciales REALES
  → Guarda y reinicia:
  sudo systemctl restart pages_qr

✅ ¡LISTO! Accede a http://TU_IP

🛠️ COMANDOS ÚTILES:
─────────────────────────────────────────────────────────────────

Ver estado:
  sudo systemctl status pages_qr

Ver logs:
  sudo journalctl -u pages_qr -f

Reiniciar:
  sudo systemctl restart pages_qr

Actualizar código:
  cd /home/appuser/pages_qr && git pull && sudo systemctl restart pages_qr


🆘 SI ALGO FALLA:
─────────────────────────────────────────────────────────────────

502 Bad Gateway:
  sudo systemctl restart pages_qr

Connection refused:
  sudo systemctl status pages_qr

Ver logs de error:
  sudo journalctl -u pages_qr -n 50
